# Lista previa a la demostración

- [ ] Oracle está disponible. Flyway reconoce V4 y el backend valida el esquema.
- [ ] Redis responde. El esquema y la base lógica son exclusivos del laboratorio.
- [ ] Los datos sintéticos están cargados. Preparar un cliente de prueba y un producto activo con dos unidades o más.
- [ ] El perfil dev está activo y Actuator devuelve el estado esperado.
- [ ] Frontend y API corresponden a la etiqueta `v1.0-demo`. Verificar compilación.
- [ ] Los usuarios de demostración tienen roles de vendedor, almacén y administrador. Las claves se suministran por variables de entorno.
- [ ] Abrir ventanas separadas, con sesiones cerradas. Preparar Productos, Ventas, Auditoría, el log y el informe HTML.
- [ ] Si falla el entorno, usar el video y las capturas del índice. Reintentar una venta solo tras comprobar que no se registró.
